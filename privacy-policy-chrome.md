# Privacy Policy for PhishGuard KE Chrome Extension

**Last Updated:** December 2024

## Overview

PhishGuard KE is a Chrome extension designed to protect users from phishing websites targeting East Africans. This privacy policy explains how we collect, use, and protect your information when you use our extension.

## Information We Collect

### Automatically Collected Data

**URLs and Page Content:**
- URLs of websites you visit (for phishing analysis only)
- Page text content (extracted for scam detection)
- Domain information (for typosquatting detection)

**Technical Data:**
- Extension version and browser information
- API response times (for performance monitoring)
- Error logs (for debugging purposes)

### User-Provided Data

**Optional Reporting:**
- URLs you manually report as suspicious
- Optional comments when reporting sites
- No personal information is required for reporting

## How We Use Your Information

### Primary Purpose: Security Analysis
- **Phishing Detection:** Analyze URLs and content to identify potential threats
- **Brand Protection:** Detect impersonation of legitimate East African brands
- **Risk Assessment:** Generate risk scores and safety recommendations

### Secondary Purposes
- **Service Improvement:** Enhance detection algorithms and accuracy
- **Community Protection:** Build database of known threats (anonymized)
- **Performance Optimization:** Monitor and improve extension performance

## Data Processing and Storage

### Real-Time Analysis
- URL and content analysis happens in real-time
- Data is processed server-side using secure APIs
- Analysis results are temporarily cached for performance

### Data Retention
- **URLs:** Temporarily stored for caching (24-48 hours maximum)
- **Analysis Results:** Cached for improved performance (7 days maximum)
- **User Reports:** Stored indefinitely for community protection (anonymized)
- **Personal Data:** We do not collect or store personal information

### Data Security
- All data transmission uses HTTPS encryption
- Server-side processing with secure API endpoints
- No local storage of sensitive information
- Regular security audits and updates

## Third-Party Services

### OpenAI API
- We use OpenAI's API for advanced content analysis
- Only URL and page content are sent to OpenAI
- No personal information is shared with OpenAI
- Data processing subject to OpenAI's privacy policy

### No Other Third Parties
- We do not share data with advertising networks
- No analytics tracking or user profiling
- No data sales or commercial use of user information

## Browser Permissions Explained

### Required Permissions

**`activeTab`**
- **Purpose:** Access current tab's URL and content for analysis
- **Usage:** Only when actively checking for phishing threats
- **Limitation:** No background monitoring of inactive tabs

**`storage`**
- **Purpose:** Store user preferences and temporary cache
- **Usage:** Remember user's "proceed anyway" decisions
- **Data:** Only extension settings, no personal information

**`tabs`**
- **Purpose:** Monitor tab changes for real-time protection
- **Usage:** Trigger security checks on new page loads
- **Limitation:** Only URL access, no browsing history storage

**`host_permissions` (all URLs)**
- **Purpose:** Analyze any website for phishing threats
- **Justification:** Phishing sites can appear on any domain
- **Usage:** Content analysis for security purposes only
